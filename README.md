# KiVault

KiVault is a local-first, security-focused desktop application designed for managing personal accounts, credentials, and sensitive records securely on your local device.

## Key Attributes

- **Desktop Application**: Pure desktop experience using Tauri 2.
- **Security-First Architecture**: Strong local cryptographic vault isolation and zero cloud/online authentication dependencies.
- **Local-First Storage**: Vault data is encrypted and saved locally in custom `.kivault` files.

## Technology Stack

- **Desktop Core & Security**: [Tauri 2](https://v2.tauri.app/) + [Rust](https://www.rust-lang.org/)
- **Frontend UI**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)

## Project Status

- **Current Stage**: Repository structure, configuration hygiene, and module organization phase.
- Application logic and vault/crypto features will be implemented in subsequent development phases.
